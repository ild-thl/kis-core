# System

Was für die ganze Plattform gilt, verteilt auf drei Reiter.

## Betrieb

- **Wartungsmodus**: an heißt, alle ohne das Recht Zugriff während der Wartung bekommen eine
  Wartungsseite statt der App. Nötig zum Beispiel vor einem Neu-Indexieren der Materialien.
- **Hinweis auf Startseite**: ein Text als Leiste über dem Menü, bei allen Personen, aufklappbar,
  eingeklappt steht dort nur das Wort Hinweis. Links im Text stehen als [Beschriftung](Adresse).
  Ein leeres Feld heißt, auch bei eingeschaltetem Schalter bleibt der Hinweis verborgen.
- **Begrüßungsfenster beim ersten Login**: ein Text, der jedem Konto genau einmal direkt nach der
  allerersten Anmeldung angezeigt wird, danach nicht wieder. Wer es sieht, braucht zusätzlich ein
  eigenes Recht in der Rechtematrix.

## Rechtliches

- **Impressum und Datenschutzerklärung**: je ein Text auf Deutsch und Englisch, in Markdown. Fehlt
  der englische, erscheint der deutsche. Fehlt ein Text ganz, zeigt die Seite nur einen Hinweis.
- **Kontakt-E-Mail**: erscheint bei Anmeldung, Freischaltung und auf der Startseite. Bleibt sie
  leer, verschwinden die Kontakt-Links.

## Campus Map

Die Adresse der Kartenseite. Die Karte liegt außerhalb der Plattform, die Ortsliste für den
Infoassistenten und das Vorschaubild im Footer liegen daneben. Ein leeres Feld oder der Schalter
auf Aus heißt: keine Karte, keine Kachel im Footer, keine Ortskarten im Infoassistenten. Wie sich
die Karte auf anderen Seiten einbinden lässt, steht im Artikel Campusplan.
